# Over the Hedge AP Manual
Archipelago Manual APWorld of the Over the Hedge video game, released for GCN, PS2, and PC. The game is a beat-em-up collectathon whose events take place almost entirely after the movie. This Manual expects the use of a custom save file, which is provided (currently only GCN).
## Items
- Characters (RJ, Verne, Hammy, and Stella) (two random characters of the four are chosen to start with).
- Heist Plans (serve as unlocks for sets of levels, grouped as heists).
- Minigame Unlocks (toggle)
- Ability Upgrades (instant power golf, upgraded health, upgraded damage, activated via in-game cheat codes)
## Locations
- Level completion
- Cookies (toggle)
- Chips (toggle)
- DVDs (toggle)
- Hats (toggle)
- Minigame completion (toggle)
## Goal Requirements
- Complete final level (Rescue Heather)
  - Requires all four characters and the Vermtech Rescue Plans

## Cheat Codes
To input the following cheat codes, pause the game in the Woods and hold L+R while inputting. These codes are for the GCN version specifically (they differ per version). "Unlock All Levels" and "Unlock All Minigames" are not needed as the save file already unlocks them all, but I've included the codes anyway.
- Increased Damage: Y, X, Y, X, Y, B
- Increased Healing: Y, X, Y, X, B, Y
- Instant Power Golf: Y, X, Y, X, B, X
- Unlock All Levels: Y, X, Y, X, X, B
- Unlock All Minigames: Y, X, Y, Y, B, B
